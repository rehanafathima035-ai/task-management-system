# Task Management System

A web-based Task Management System built with Flask that allows users to manage their tasks through a simple and organized interface.

## 🚀 Overview

The Task Management System is designed to make it easier to create, view, update, and manage tasks from a centralized web application.

The project demonstrates the fundamentals of building a Python-based web application using Flask, HTML/CSS, templates, and application-side task management.

## ✨ Features

- Create and manage tasks
- View existing tasks
- Update task information
- Track task status
- Delete tasks
- Simple and user-friendly web interface
- Server-side application logic using Flask
- Template-based frontend using Jinja2
